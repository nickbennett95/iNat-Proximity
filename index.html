Getting your iNaturalist API token
  1. Log in to inaturalist.org in your browser.
  2. Go to inaturalist.org/users/api_token
  3. Copy the token shown on that page.
  4. Paste it into the API Token field.
Your token is only used to make requests to iNaturalist and is never stored or sent anywhere else. Tokens expire after 24 hours.
